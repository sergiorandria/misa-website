## Important identity updates

The screenshot contains legacy labels for Toulouse III and Paris Diderot, and a legacy/short label for Paris 13. The current identities are **Université de Toulouse**, **Université Paris Cité**, and **Université Sorbonne Paris Nord**, respectively. Telma Madagascar’s website currently redirects to **Yas Madagascar**, so the package includes Yas as the current brand.
